### 都有家谱

**前端开发工程师 · 2025.07 — 至今**

**技术栈：** Vue 3、Pinia、es-drager、html2canvas / html-to-image、IndexedDB、Tailwind CSS。

1. 实现递归树形组件，通过 Map 缓存将节点查找复杂度降至 O(1)，支持子节点懒加载、动态展开与折叠，以及 nodeMap / parentMap 节点关系映射，保障千人级数据流畅渲染。
2. 集成 es-drager 实现谱册拖拽式编辑，基于 contenteditable 开发原生文本编辑，通过事件委托处理 focus、blur、dblclick 实现编辑态切换，结合深拷贝与 nextTick 确保数据双向绑定准确。
3. 搭建智能导出系统，根据 DOM 尺寸自适应处理，宽度超过 5000px 时自动分片，使用 html2canvas / html-to-image 进行 Canvas 渲染，以 IndexedDB 存储切片，配合后端完成图片拼接，支持进度追踪与错误恢复。
4. 通过迭代替代递归（如 expandAll）、Map 缓存节点映射、深度监听优化、DOM 滚动定位及 IndexedDB 异步存储，提升大数据量交互与导出效率。
